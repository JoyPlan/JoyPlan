# JoyPlan: AI-Powered Smart Family Experience System

## Project Description
JoyPlan is an AI-powered system that helps families plan a personalized day out based on their children's needs. The family enters the children's ages, mood, interests, energy level, budget, location, available time, and food preferences.

The AI analyzes these inputs, then ranks suitable activities, restaurants, snacks, and break times. It then generates a complete daily itinerary that fits the family's time and budget.

## Main AI Features
- Personalized recommendations for activities, restaurants, and snacks
- Smart itinerary generation that fits the family's time and budget
