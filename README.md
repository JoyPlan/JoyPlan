# JoyPlan: AI-Powered Smart Family Experience System

**Course:** SWE 401 – Software Engineering | Abu Dhabi University
**Instructor:** Dr. Murad Al-Rajab

## Project Description
JoyPlan is an AI-powered Java web application that helps families plan a personalised day out based on their children's needs. It works in the browser on any phone or computer. The parent enters the children's ages, mood, interests, energy level, budget, location, available time and food preferences.

A recommendation algorithm ranks suitable activities, restaurants, snacks and break times. An AI model then generates a complete, timed day plan that fits the family's time and budget.

## Main Functions
| ID | Function | Description |
|----|----------|-------------|
| F1 | Family profile | Save the children's ages, interests and food preferences |
| F2 | Outing details | Enter mood, energy, budget, location, time and indoor/outdoor choice |
| F3 | Smart recommendations | Rank suitable activities, restaurants, snacks and breaks |
| F4 | AI day plan | Generate a timed plan within budget and time, explaining each stop |
| F5 | Edit and regenerate | Swap one stop or create a new plan |
| F6 | Save, rate and navigate | Save and rate plans; get directions in Google Maps |

## Methodology
Throwaway Prototyping (RAD). Quick prototypes (an AI plan test and Figma page mockups) are built and tested with parents, then discarded. What we learn is used in the final design.

## Technologies
- Java, Spring Boot, IntelliJ IDEA
- HTML, CSS, Thymeleaf, Bootstrap
- MySQL, Spring Security
- ChatGPT (OpenAI API) or Gemini API
- Google Maps, Figma, JUnit
